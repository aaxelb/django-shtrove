# shtrove
helpful interfaces and tools for cataloging metadata records

## extract
from an input document, extract a catalog record -- see [shtrove.extract](./extract/README.md)

## persist
store catalog records for easy retrieval -- see [shtrove.store](./store/README.md)

## derive
represent a catalog record in a specific way -- see [shtrove.derive](./derive/README.md)

## index
make a bunch of catalog records more easily searchable -- see [shtrove.index](./index/README.md)

## render
serialize an api response -- see [shtrove.render](./render/README.md)
